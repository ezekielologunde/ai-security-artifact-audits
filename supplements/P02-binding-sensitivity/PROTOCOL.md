# Controlled evidence-attribution sensitivity study

19 November 2026. Written before generating the factorial dataset or executing the comparison. Source-informed engineering experiment: strict-mode grammar and the prior cross-example diagnostic are already known. This is neither blinded validation nor a novelty claim.

Question: under a declared configuration-route contract, how do README-wide versus explicitly selected-call checks respond to distractors and unsupported but unambiguous documented call styles?

Generate all 72 combinations of three selected call styles (direct literal AutoModel, a preceding literal model-ID assignment, and a module-qualified class), two literal remote-code flags, three distractor conditions (none, an enabled call for another model, and enabled text in an HTML comment), two call layouts (one/multiple lines), and presence/absence of a declared local AutoModel mapping. Keep every case, including unsupported styles. The selected call line is supplied to both modes in exactly the same snapshot. Do not supply reference labels to either checker.

The reference property is fixed by construction: the selected example targets the named fixture model and class; its Boolean flag and the mapping-presence factor determine whether that example selects the declared custom-mapping route. This is a reference about authored documentation/configuration evidence, not actual successful loading, repository safety, true training provenance, or malicious execution. Model code and weight contents are uninspected; no runtime-security truth labels exist. In particular, a false reference property is not proof of safe loading.

Compare the current implementation's default `overlay` and opt-in `overlay_bound_loader`, using one preserved byte-identical implementation. Record whether `loading_exposure` fires as `observed-loading-exposure`. Report TP/FP/FN/TN only as *constructed evidence-route conformance*, not malware detection or natural claim accuracy; state that strict mode may abstain rather than assert a negative. Report all 72 cases and strata by style, distractor and layout, plus paired disagreement counts. No significance or population generalization from enumerated authored cases. Both systems receive the same selector information, but default mode does not consume the call-line field; any benefit is conditional on supplying that extra annotation, whose acquisition cost is not measured here.
